# iOS IPSW Web App Example

A GitHub Pages and GitHub Codespaces-ready web application simulating an iOS IPSW management dashboard that interfaces with iTunes setup utilities on Windows.

## Features
- **IPSW Catalog**: View and download iOS firmware bundles.
- **iTunes Integration**: Script templates to trigger iTunes setups on Windows.
- **Codespaces Ready**: Includes devcontainer configuration with Python, Perl, and PHP support.
